# Living Lattice — accent panel (example)

460 × 240 mm asanoha, swappable zigzag tiles, wall pegs. Regenerated with:

```bash
node cli/generate.js --params examples/living-lattice-accent/params.json --out examples/living-lattice-accent
```

Includes `living_lattice_460x240.3mf` (Bambu Studio: 0.2 mm / 4 walls / mouse-ear brim on tiles+frame) and `wall_template_letter_pages.pdf` for home-printer wall marking.
